###0.9.1
- Media: new "Show as" option (Settings > Sections & apps > Media). Text only shows one line per item, the title with its episode or release type and the date on the right, with a tick when it is already downloaded, so many more items fit. Posters stays the default.

###0.9.0
- Alerts: a disk that Scrutiny marks as failed is a red alert ("sdb (WD…) failed its SMART check"), kept in the alert history and can be ignored like any other. The background check asks Scrutiny every 5 minutes; the alert ends only when Scrutiny has been asked again and says the disk is fine.
- GitHub releases: "Add from my containers" lists your containers with the GitHub repository each comes from (the image's source label, or a ghcr.io image name) to follow with a tick. A repository that cannot be read now shows as its own row instead of hiding the others.
- Security: while the Docker version has no password, it only answers at the server's IP address or name (tower, tower.local) and the names in the new UNDASH_ALLOWED_HOSTS setting. Before, a web page could point a host name of its own at your server (DNS rebinding) and use the dashboard through your browser. With a password nothing changes.
- Security: wrong passwords are also counted for all addresses together (30 in 15 minutes), on top of 5 per address.
- Security: a value with a carriage return (a pasted key, for example) could add a line to .env. Line breaks are now always escaped.
- Security: changing the Unraid API address to another server asks for the API key again, so the saved key is never sent to a new address.
- Security: without a dashboard password, the .env file (every key) cannot be downloaded from Settings > Backup.
- Media links only point to web addresses.

###0.8.0
- Icon picker: "Browse" next to an app's Icon field, and a click on a container's or VM's icon in Settings, searches about 5,000 icons from selfh.st icons and dashboard-icons by name. The server downloads the two name lists once a week; the images load from the same CDN as before.
- New apps: Scrutiny (disks passed / failed, hottest disk, failed disks listed), Tdarr (queue, processed, errored, space saved), Unmanic (workers, pending), Uptime Kuma (a status page's monitors up and down, uptime, down monitors listed), Speedtest Tracker (latest download, upload and ping; old and new API), Gluetun (VPN public IP, location, forwarded port) and Home Assistant (chosen entities, or people home, lights and switches on). Each is also found among your containers.
- New widgets (Add app > Widgets): Weather from Open-Meteo (no key; a town or coordinates, °C or °F) with today and the next three days; GitHub releases, the latest release of the repositories you list, newest first, checked at most once an hour (a GitHub token is optional); Bookmarks, a list of links (Title | https://…).
- Lists in app cards can link their rows and show a second, quieter line.
- Custom API: a new display, "A row for each item of a list", turns any JSON list into rows: where the list is, then Title, Second line, Right side, Date and Link written with fields in braces ({name}, {size|bytes}, {user.name}). Formats: bytes, rate, percent, number, round, date, upper, lower. Number blocks can use a template too ({"template": "{up} / {total}"}). Test shows the first rows.
- Tdarr and Unmanic get their icons (selfh.st has them as PNG only).
- Fixed: on PHP 8.5 a deprecation notice could break an answer from the server (curl_close).

###0.6.1
- Much faster loading in Docker. The page no longer waits for a full server read before it appears, and live refreshes no longer wait for the two slow parts of the Unraid API (network rates and the server's address, about 2 s each on a busy server): a background task keeps them fresh while the dashboard is open.
- More parallel requests: the container serves 12 at a time (was 4), and the page keeps app and media reads to 4 at a time, so the live refresh and your clicks never queue behind a slow app.
- Prowlarr's grab and query totals are kept for 10 minutes; Prowlarr needs 10 s and more to work them out on every request.
- Several browsers asking for the same app at the same moment share one request.
- Less clutter: the UPS tile hides itself when there is no UPS, Uptime shows since when instead of repeating the Unraid version, VMs drop the empty vCPU and memory columns in the Docker version, requests are one compact line each, and app cards with four numbers show them as two even rows.
